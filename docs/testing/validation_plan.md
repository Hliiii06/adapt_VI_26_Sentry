# 验证计划

本轮只完成静态架构阅读和文档核对。下表是未来实施后的验收方案，**不是本轮已执行测试**；SCAN 适配实车测试为最后阶段。现有 RM 的 RViz 2D goal 导航已由用户验证，作为回归对照基线。

## 第一轮只需看懂的独立仿真验收

先做以下 S 阶段测试；后文的 RM TF 交接、UART、电控 watchdog 与 Nav2 切换属于接车阶段，不阻塞独立仿真开发。仿真数据中断停车仍需测试。

| 场景 | 用户应看到什么 | 留给审查者的证据 |
|---|---|---|
| 启动 PCD + RViz | 地图、车体、方向箭头、碰撞包络正确显示 | 启动命令、PCD 路径/校验值、尺寸参数、RViz 配置 |
| 三种模式 | 点目标、多航点、参考路线分别能驱动机器人运动 | 每模式操作步骤与结果，不只节点启动日志 |
| 不转头横移 | 车头方向不变，机器人侧向走到目标 | 实际 odom 与目标/轨迹对比，yaw 和 XY 误差 |
| 边旋转边走 | 车体转动时，移动方向不跟着错误旋转 | odom yaw、世界系轨迹、body 速度记录 |
| 窄处与障碍 | 中心线没碰墙但车体放不下时，拒绝或绕行 | 独立几何检查/真实外形覆盖，不能只用规划器自身判断证明自身正确 |
| 取消/断流 | 取消目标、停止 odom 或控制输入后不持续跑旧命令 | 明确时间阈值、实际停止时间和日志 |
| 带高度路线 | 高度偏置正确，显示与模拟规则一致 | 说明高度模型；不当作真实爬坡验证 |

闭环检查：确认模拟 odom 来自速度积分；更改跟踪增益/限速应改变执行效果，不能无条件精确贴合样条。记录最大/均方 XY 跟踪误差、yaw 测试范围、最小障碍间距、停止时间与阈值。未测试标“未测”，不能用一张 RViz 截图代替记录。

## 验证矩阵

| 对象 | 方法与场景 | 验收标准/记录 |
|---|---|---|
| 版本/依赖 | 记录 Git SHA、dirty diff、ROS/Nav2/overlay、参数 | 与文档基线一致；不存在无说明旧 install 覆盖 |
| TF 组合 | 单位姿态、90° yaw + 非零杆臂、roll/pitch、初始化位置非零 | 与 `T_parent_body × T_body_sensor` 等显式公式结果一致；闭合误差阈值在契约评审确定 |
| TF 所有权 | 无重定位、启动交接、重定位失败/重启 | 同一 child 无竞争父节点；无环；失效状态可检测；旧轨迹按规则失效 |
| 速度语义 | 机身 x 前进、y 横移、旋转、组合运动 | world/body 旋转和杆臂补偿正确；速度非默认零；单位/符号有依据 |
| 传感器输入 | sensor pose 与原始云同屏；延迟/乱序/缺 TF/掉帧 | 射线起点与云一致；拒绝或暂停过时输入；报告实际延迟/频率 |
| QoS | 启动顺序变化、先发路径再启动、重连 | 流式数据可连接；路线不静默丢失或误复用；明确重发/确认策略 |
| Mode 1/2/3 | 初始无 odom、空路径、重复点、NaN、不同 z、短路线 | 无非法轨迹；Mode 1 高度、Mode 3 地面 z+body_height 符合契约 |
| 碰撞模型 | 前/侧移、原地旋转、窄门、低矮横梁、底盘净空 | 实际机器人包络全部被检查；与切线 yaw 不一致时仍满足规则 |
| 参考高度 | Mode 1 平地目标；Mode 3 已知可通行、带高度路线 | 地面 z + body_height 只应用一次；验证空间避障与 XY 跟踪；不要求自由跨层搜索或自动悬崖识别 |
| 未知地图 | 滑窗边界、未观测空洞、传感器盲区 | 不把未观测自由空间当可行地面；越界行为明确 |
| 跟踪 | 直线/转弯/横移/反向/动态更新路线 | 记录横向误差、速度和加速度、轨迹时间漂移；阈值按底盘能力确定 |
| 控制模式 | yaw 对齐、陀螺/扫描、特殊区域 | 全向平移与朝向策略不死锁；协议字段正确；不误把 linear.z 当升降速度 |
| 停止 | 无 odom、无云、规划失败、controller 重启、任务取消/抢占 | 在确定超时内输出/执行停止；无旧指令持续运行；固件 watchdog 独立验证 |
| A/B 命令仲裁 | Nav2/SCAN 切换、behavior_server 恢复同时发命令 | 最终仅一个授权控制源；切换无速度跳变或旧目标复活 |
| 任务结果 | 到达、不可达、重规划失败、用户取消 | ID、反馈、结果、失败原因和停止确认一致；不把 DataDisp 充当结果 |

## 可视化应同时展示

原始云、经过适配的云、sensor 原点/朝向、body 真实姿态与体积、地面参考高度、规划路线、B-spline 和执行轨迹、地图未知/边界、TF。参考路线限定在已知可通行场地，不把仿真样条显示成功等同于实车跟踪成功。

## 实车前还缺的量化条件

机器人尺寸与运动上限、允许跟踪误差、最大数据年龄/停止时间、当前选定场地约束尚待记录。不能凭文档自行编造安全数值。由用户和硬件条件确认后写入契约与参数快照，再开始实车验证。
